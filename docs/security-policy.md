# 安全策略

## 工具定位

webvuln-analyzer 是 **源代码静态分析器**。它帮助开发者与审计人员在有授权的代码库上发现常见缺陷模式。

允许：

- 扫描自己维护或被明确授权审计的 Web 服务代码
- 把结果用于修复、代码评审、CI 门禁
- 扩展规则以提高检测质量

不允许把本工具用于：

- 未授权访问、扫描或攻击他人的在线服务
- 编写、传播漏洞利用代码或攻击步骤
- 绕过访问控制去读取受保护的文件或密钥

`fixtures/` 中的示例仅用于验证检测器，不是可部署的靶场服务。

## 发现本仓库自身的问题

如果你发现扫描器自己的缺陷（例如任意文件写入、依赖漏洞），请不要在公开 issue 里附带可直接利用的细节。描述影响范围、受影响版本和复现所需的最小输入即可。

维护者收到报告后应：

1. 确认是否可在本地只读复现
2. 准备修复与回归测试
3. 在 CHANGELOG 记录安全修复，避免复制敏感细节

## 扫描结果的处理

报告可能包含硬编码密钥片段。请：

- 限制报告文件的访问权限
- 不要把 `reports/` 提交到 git（已在 `.gitignore`）
- 对确认泄露的凭据立即轮换
